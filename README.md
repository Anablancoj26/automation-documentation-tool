## 🇬🇧 English

### 📌 Project Overview
A utility script designed to automate repetitive operational tasks—such as file organization and log processing—paired with comprehensive technical documentation to ensure maintainability and ease of use.

### ✨ Key Features
- **File System Automation:** Programmatically scans directories, classifies files by extension, and organizes them efficiently.
- **Error Handling & Logging:** Captures runtime exceptions and generates execution logs.
- **Clean Documentation:** Clear architectural notes and usage guidelines.

### 🛠️ Tech Stack
- **Language:** Python (Standard Libraries: `os`, `shutil`, `pathlib`)
- **Version Control:** Git & GitHub

## 🇪🇸 Español

### 📌 Descripción del Proyecto
Script de utilidad diseñado para automatizar tareas operativas repetitivas (como la organización masiva de archivos y procesamiento de registros), acompañado de documentación técnica completa para garantizar su mantenibilidad y facilidad de uso.

### ✨ Características Principales
- **Automatización del Sistema de Archivos:** Escanea directorios de forma programática, clasifica archivos por extensión y los organiza eficientemente.
- **Manejo de Errores y Logs:** Captura excepciones en tiempo ejecución y genera registros detallados de las operaciones.
- **Documentación Clara:** Notas arquitectónicas y directrices de uso claras para desarrolladores.

### 🛠️ Tecnologías Utilizadas
- **Lenguaje:** Python (Librerías nativas: `os`, `shutil`, `pathlib`)
- **Control de Versiones:** Git & GitHub
